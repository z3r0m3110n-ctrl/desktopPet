# Welcome to DesktopPet!

<img width="100" height="100" alt="walk-1" src="https://github.com/user-attachments/assets/802eee2f-d22a-4f60-b3c8-fdaeef7f0e6a" align="left" />


DesktopPet is a curious creature, a cross between a llama and a sheep, which will run around on the taskbar of the screen. It will also occasionally sleep. Clicking on it, interacting with it, and moving it around will make it happy, but ignoring it will make it angry and bored. 

DesktopPet was developed for Windows and is my first ever project made in Godot.
