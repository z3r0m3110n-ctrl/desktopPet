# Welcome to DesktopPet!

<img width="100" height="100" alt="walk-1" src="https://github.com/user-attachments/assets/802eee2f-d22a-4f60-b3c8-fdaeef7f0e6a" align="left" />


DesktopPet is a curious creature, a cross between a llama and a sheep, which will run around on the taskbar of the screen. It will also occasionally sleep. Clicking on it, interacting with it, and moving it around will make it happy, but ignoring it will make it angry and bored.

All of the graphics and animations are custom-made for DesktopPet. For these, I learned how to use Gimp and created them there.

DesktopPet was developed for Windows and is my first ever project made with the Godot Engine. The first release was a chance to understand scenes and nodes function, how to add different elements, as well as use GDScript. I will add even more features as I learn more.

## Play the Game

**Windows Demo:** [Download DesktopPet](https://github.com/z3r0m3110n-ctrl/desktopPet/releases/latest)

### How to Play
1. Go to the [latest release](https://github.com/z3r0m3110n-ctrl/desktopPet/releases/latest) page
2. Download the Windows .exe file from the release assets.
3. Run 'DesktopPet.exe' to start the game.

### Controls
Use the mouse to click your pet and drag him around the screen.
